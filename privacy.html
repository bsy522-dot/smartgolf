스마트골프 개인정보처리방침

시행일: 2026년 8월 14일 · 앱: 스마트골프 (SmartGolf)

스마트골프(이하 “앱”)는 이용자의 개인정보를 소중히 여기며, 아래와 같이 처리방침을 안내합니다. 본 앱은 회원가입이 없고, 자체 서버를 운영하지 않습니다. 이용자가 앱에서 만든 기록은 원칙적으로 이용자 기기 안에만 저장됩니다.

1. 수집하는 정보와 이용 목적

항목수집 방식이용 목적보관 위치
위치정보(위도·경도) 이용자가 ‘현재 위치’ 버튼을 누른 경우에만 (선택) 출발지 기준 골프장 거리 계산, 날씨 조회 기기 내 저장, 서버 저장 없음
이용자가 입력한 주소·검색어 직접 입력 (선택) 좌표 변환(지오코딩) 및 골프장 검색 기기 내 저장, 서버 저장 없음
라운드 기록·즐겨찾기·예산·설정 이용자 입력 및 기능 이용 중 앱이 생성 앱 기능 제공(기록 관리, 통계) 기기 내 저장소(localStorage)에만 저장

  • 이름, 이메일, 전화번호, 생년월일 등 신원 정보
  • 연락처(주소록), 사진, 카메라, 마이크, 통화기록
  • 광고 식별자, 결제 정보

2. 제3자 서비스로의 정보 전송

앱은 아래 외부 서비스를 호출하며, 그 과정에서 해당 항목이 전송됩니다. 전송된 정보는 해당 기능 수행 목적에 한해 사용되며, 본 앱은 이를 별도로 저장하지 않습니다.

서비스전송 항목목적
Open-Meteo (api.open-meteo.com) 위도·경도 골프장 지역 날씨 조회
OpenStreetMap Nominatim (nominatim.openstreetmap.org) 위도·경도 또는 입력한 주소 문자열 주소↔좌표 변환, 지역 검색
OpenStreetMap 타일 서버 (tile.openstreetmap.org) IP 주소, 보고 있는 지도 영역 지도뷰의 지도 이미지 표시
OSRM (router.project-osrm.org) 출발지·골프장 좌표 자동차 기준 이동거리·소요시간 계산
unpkg CDN (unpkg.com) IP 주소 지도 라이브러리(Leaflet) 파일 내려받기

이용자가 직접 눌렀을 때만 열리는 외부 링크 — 아래는 앱이 자동으로 호출하지 않으며, 버튼을 누르면 브라우저로 이동합니다. 이동 이후에는 각 사이트의 개인정보처리방침이 적용됩니다.

  • 카카오맵(map.kakao.com), 네이버지도(map.naver.com), 네이버검색(search.naver.com), 구글지도(www.google.com/maps)
  • 김캐디(kimcaddie.com) — 골프장 예약 페이지

앱에는 광고 SDK, 분석(Analytics) SDK가 포함되어 있지 않습니다.

3. 보유 및 파기

모든 이용 기록은 이용자 기기의 브라우저 저장소(localStorage)에만 있으며, 보관 기간을 따로 두지 않고 이용자가 지울 때까지 기기에 남습니다. 운영자는 이 기록에 접근할 수 없습니다.

언제든지 아래 방법으로 전부 삭제할 수 있습니다.

  • 안드로이드 앱으로 이용 중인 경우 — 설정 > 앱 > 스마트골프 > 저장공간 > 데이터 삭제
  • 앱 내에서 — 우측 상단 메뉴의 ‘사이트 설정’에서 사이트 데이터 삭제
  • 웹브라우저로 이용 중인 경우 — 브라우저의 인터넷 사용 기록/사이트 데이터 삭제

참고로 안드로이드 앱을 삭제하더라도 브라우저에 저장된 사이트 데이터는 남을 수 있으므로, 완전히 지우려면 위 방법을 함께 이용해 주세요.

4. 이용자의 권리

  • 위치 권한은 기기 설정에서 언제든지 거부·철회할 수 있으며, 거부해도 주소 직접 입력으로 모든 기능을 이용할 수 있습니다.
  • 데이터가 기기에만 저장되므로 열람·정정·삭제를 이용자가 직접 수행합니다.

5. 아동의 개인정보

본 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

6. 보안

앱은 HTTPS로 제공되며, 외부 서비스 호출 역시 HTTPS로 이루어집니다. 자체 서버와 계정 체계가 없으므로 서버 측 개인정보 유출 위험이 존재하지 않습니다.
